# 📝 Notes Manager — Gerenciador de Notas

Um gerenciador de notas desenvolvido em Python, com armazenamento de dados utilizando SQLite. A aplicação permite criar, visualizar, pesquisar e excluir notas diretamente pelo terminal.

## 🚀 Funcionalidades

- **Criar notas:** registre o autor, título e conteúdo de uma nota.
- **Visualizar notas:** consulte todas as notas armazenadas.
- **Pesquisar notas:** encontre registros por autor, título, data ou conteúdo.
- **Excluir notas:** remova registros utilizando seu ID.
- **Armazenamento persistente:** mantenha suas notas salvas localmente em um banco de dados SQLite.

## 🛠️ Tecnologias utilizadas

- Python 3
- SQLite3
- Datetime

## ⚙️ Como executar

**1. Clone o repositório:**

```bash
git https://github.com/abrahaobraga10/Notas-Python.git
```

**2. Acesse a pasta do projeto:**

```bash
cd Notes_Python/Note
```

**3. Execute a aplicação:**

```bash
python3 notas.py
```
